Visionance renders enhancement on your GPU in real time. Online playback is resolved with yt-dlp; only sources you are entitled to access should be used.

How Visionance works

Every frame passes through four GPU shader stages before it reaches your screen:

  1. Restore — edge-aware denoise and compression-artefact cleanup at source resolution, so noise never gets magnified.
  2. Reconstruct — Catmull-Rom resampling plus edge-directed correction, which removes staircase edges instead of blurring them.
  3. Sharpen — contrast-adaptive sharpening: strong where the picture is soft, restrained where it is already detailed, with halo suppression.
  4. Finish — debanding, local contrast, tone curve and colour.

Nothing is written to disk and nothing is re-encoded, so a 1080p stream can look close to a native 4K file without the 20 GB download or the wait.

When you do need a file — for editing, uploading or sending to someone — the Export tab renders the same look with ffmpeg.
